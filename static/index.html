Built for running code you don't trust yet

A small API in front of Kubernetes. No servers to set up and nothing left running afterwards.

📦

A new pod for every run

Your code runs in its own python:3.11-slim container. Nothing carries over between runs.

🔒

Your files stay yours

Each submission is mounted from its own folder, so a running program can't see anyone else's code.

⏱️

Time and memory limits

Runs stop after 15 seconds and are capped at 250m CPU and 128Mi of memory. Infinite loops can't hog the cluster.

From editor to output in four steps

  1. Sign inCreate an account and get a signed token for your session.
  2. Submit your codeThe API saves it to your own folder on shared storage.
  3. A pod runs itKubernetes starts a container that can only see that folder.
  4. Read the outputLogs come back to your screen and the pod is deleted.
# or skip the editor and use the API
$ curl -X POST /execute \
    -H "Authorization: Bearer $TOKEN" \
    -d '{"code": "print(2 + 2)"}'

{"status": "Succeeded",
 "output": "4\n"}
